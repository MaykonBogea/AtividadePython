# 📌 Entregável de Desenvolvimento em Python – Semana 01 (Desafio Sprint 1)

O que deve ser entregue?

Finalização da resolução dos 6 mini-desafios da Prática Independente, aplicando os conceitos fundamentais da linguagem Python, como sintaxe, variáveis, tipos primitivos, operadores, entrada/saída de dados e manipulação de strings.

Os desafios devem ser entregues em arquivos .py (um para cada desafio ou um único arquivo com todos) e devem apresentar:

Calculadora de troco: Recebe o valor da compra e o valor pago, calcula e imprime o troco.

Média de notas: Recebe 3 notas via input(), calcula e imprime a média com 2 casas decimais.

Conversor de tempo: Recebe um valor em segundos e imprime o equivalente em horas, minutos e segundos.

Calculadora de desconto: Recebe o preço de um produto e o percentual de desconto, imprime o preço final.

Par ou ímpar: Recebe um número inteiro e informa se ele é par ou ímpar (utilizando o operador de módulo %).

Inversor de nome: Recebe um nome e imprime o nome invertido utilizando slicing [::-1].

Certifique-se de que todos os códigos rodam sem erros e que os arquivos estejam com as permissões de acesso liberadas para visualização.

Objetivo da atividade

A construção desses scripts ajudará a equipe a fixar os fundamentos da programação em Python, compreendendo na prática como declarar variáveis, realizar operações matemáticas, capturar dados do usuário e formatar saídas. Além disso, a resolução dos desafios desenvolve o raciocínio lógico para a resolução de problemas, servindo como base fundamental antes de avançar para estruturas de controle (condicionais e laços) nas próximas aulas.

💡 Dica: Lembrem-se de que a função input() sempre retorna uma string, então não esqueçam de fazer a conversão de tipos (como int() ou float()) antes de realizar cálculos. Utilizem f-strings para formatar a saída de dados de forma clara e apliquem as convenções da PEP 8 (nomes de variáveis descritivos em snake_case).
